# Library Management System

A console-based Library Management System developed using **C++ and Object-Oriented Programming (OOP)**. The project is designed to simplify library operations by managing book inventories, member borrowing activities, returns, due dates and overdue fines.

The system supports three categories of library members: **Students, Faculty and Staff**, each with different borrowing limits, borrowing periods and renewal policies.

It also includes an **Administrator Dashboard** with authenticated access to manage books, monitor borrowing records, track overdue books and check book availability.

### Key Features
- Book inventory management with genre, author, copy count and shelf location.
- Book searching by ID, title or author.
- Separate borrowing policies for students, faculty and staff.
- Book borrowing, returning and renewal facilities.
- Automatic due-date calculation.
- Overdue book tracking and late-fine calculation.
- Administrator login and management dashboard.
- Borrowing history and availability tracking.

### Technologies Used
- C++
- Object-Oriented Programming
- Standard Template Library (STL)
- Vectors and Classes

**Project Type:** Group Project  
**Interface:** Console-based
